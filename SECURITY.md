## Reporting a Vulnerability

If you discover a security vulnerability within this repository (such as credential exposure, insecure Kubernetes RBAC rules, or network ingress vulnerabilities), please **do not report it through public GitHub issues**.

Instead, please report the vulnerability responsibly by contacting the repository maintainers directly or emailing Google Cloud Security through official responsible disclosure channels.

We will review the report promptly and publish an updated patch or security advisory.
